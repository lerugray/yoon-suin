## Add an Excalidraw drawing

1. Open this note in Obsidian.
2. Cmd+P → "Excalidraw: Create new drawing IN the current file" or
   "Excalidraw: Create new drawing IN the current folder".
3. Sketch (or compose with shapes — Excalidraw is good for
   structured diagrams even when you don't draw).
4. Save. Renders inline here in the published vault.

You can also create standalone `.excalidraw.md` files in this folder
if you prefer drawings separated from text notes.
